**FLA — Financial Liquidity Assurance**

Plataforma de monitoramento financeiro desenvolvida para acompanhar indicadores de liquidez e demonstrar a identificação de possíveis riscos financeiros.

Sobre o projeto

O FLA é um projeto de portfólio que busca representar uma solução de monitoramento financeiro, com foco em liquidez, análise de riscos e visualização de indicadores.

Funcionalidades

* Painel de monitoramento financeiro.
* Indicador de liquidez.
* Classificação demonstrativa de risco.
* Gráfico de acompanhamento da liquidez.
* Atualização dos indicadores conforme os valores informados.

Tecnologias utilizadas

**HTML**
**CSS**
**JavaScript**
**Chart.js**

[ Acessar o FLA ](https://owkevy.github.io/FLA-2.0/)


Observação

Os dados e critérios utilizados atualmente são simulados e têm finalidade demonstrativa. O projeto não possui integração com sistemas bancários reais.
